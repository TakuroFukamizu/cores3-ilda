# CoreS3 ILDA評価基板 Rev.A

2026-10-02 / KiCad 10.0.6 / 2層・280 × 202.84 mm。手はんだと測定を優先した試作設計です。回路図ERC、PCB DRC、回路図とPCBの一致検査はすべて問題0件。実基板での動作・熱・ノイズ・機械的嵌合は未検証です。

- `kicad/CoreS3_ILDA_RevA.kicad_pro` をKiCad 10で開く。回路図はルート＋13子シート。ローカルシンボル・フットプリントを同梱。

J1のM5-BusはM5Stack公式CoreS3 Module Type Aデータ由来の**表面実装**パターンです。調達候補はM5Stack **A117 / Bus Socket SMD 13.2**。一般的な2×15スルーホールソケットとは互換ではありません。CoreS3本体投影は50×50 mm、位置決め穴と支持穴を設けています。基板の下面へのバス貫通実装はありません。発注前に配置図を原寸印刷し、購入するコネクタ・CoreS3底部と合わせてください。ケース、底部モジュール、スペーサー高さによる干渉は実物確認が必要です。

## 回路構成

MCP4922-E/P×3を3.3V駆動し、共通2.048V基準・共通LDACで6chを更新します。NJM4580DD×4でX/Y差動、RGBのGND基準出力、1.024V中点バッファを構成します。RGBの能動差動には追加NJM4580×2が必要なため、U9/U10と関連部品をオプション実装にしました。

5VからMCW03-05D12で±12Vを生成。AGNDとDGNDは連続した共通GNDプレーンです。DC/DCの出力COMもGNDへ接続するため、この基板全体はガルバニック絶縁されません。SPI配線下のGNDを分断せず、DAC基準とアナログ回路を電源・リレーから分離して配置しています。各ICの電源に100nF、基準に1µFと分散100nFを配置しています。

### 電源・実装

- J2：安定化5V入力。2A供給可能な電源を推奨。極性はシルクと回路図で確認。
- JP1：**1–2＝外部5V（標準）／2–3＝M5-Bus 5V**。同時短絡禁止。標準構成ではCoreS3をUSB等から別途給電します。バス給電はCoreS3側電源容量を確認してから使用。
- F1：基板上の端子台に、絶縁した外付けヒューズホルダー＋T2Aヒューズを接続します。単なるワイヤーで置換しないでください。
- J2/J3/J4/F1の端子台ピッチは**5.00 mm**。5.08 mm品の無理な装着は避け、フットプリントに一致する品を購入。
- R1/R2＝330Ω・2Wは各±12V出力の最小負荷確保用。約36mA／0.44Wを消費するので基板から約5mm浮かせて実装。熱くなります。
- MCW03の各レールは125mA定格。6個のオペアンプを実装した場合、無負荷時の保守的な見積りは負荷抵抗36mA＋オペアンプ54mA＝約90mA/レール。外部負荷分も含めて確認してください。出力コンデンサは各22µF＋デカップリングで、メーカーの容量性負荷上限100µF/レール以内です。
- C4は**プラス側がGND、マイナス側が−12V**。C1は16V以上（25V品も外径6.3mm・ピッチ2.5mmに適合すれば可）、C3/C4は25V以上。
- MCP1501はSOT23-6、Q1はSOT23です。DIP部品のほか、この2点とM5-Busは表面実装が必要です。
- DB25は秋月DMR-25SGG用の専用パターン。外部パネルとねじ／ケーブル支持を併用し、はんだ接合だけにケーブル荷重を掛けないでください。

## DAC設定とアナログ出力

MCP4922のVREF A/Bは2.048V、VDDは3.3V。初期設定はSPI mode 0、MSB first、16bit、1MHz。BUF=0（基準入力アンバッファ）、GA=1（利得1）、SHDNビット=1（動作）です。

```text
Channel A command = 0x3000 | (code & 0x0FFF)
Channel B command = 0xB000 | (code & 0x0FFF)
6chを各CSで書き込み → 全CSをHigh → 共通LDACをLow 1µs → High
```

DAC出力はcode×0.5mV、最大code4095で2.0475Vです。ハードウェアSHDN（pin9）はDAC_RUNでプルアップ、JP3は通常OPEN。**JP3短絡によるSHDNはX/Yの中央保持にはなりません**。出力が高インピーダンスとなり、後段で偏った位置へ動く可能性があります。レーザーOFFにはENABLE／ARM回路を使用します。

|出力|公称式・範囲（出力抵抗前）|
|---|---|
|X+/Y+|4.7×(VDAC−1.024V)、約−4.813〜+4.810V|
|X−/Y−|対応する＋出力の反転|
|X/Y差動|約−9.626〜+9.621V、code2048で0V|
|RGB GND基準|2.42×VDAC、0〜4.955V|
|RGB能動差動|＋側1.22×VDAC、−側その反転、差分0〜4.996V|

出力の各線に100Ωを入れています。RGBはリレー出力側に10kΩのプルダウンもあるため、外部無負荷でもDB25側の公称最大差分はGND基準約4.906V／能動差動約4.946Vです。プロジェクタの入力負荷でさらに変わります。抵抗は調達しやすい1%品を基本としたため、中心・利得は実測校正してください。公差を含む最大値は公称値を超え得ます。初期ソフト上限はRGB code3900以下から始め、実測して5V差動を超えない範囲に設定します。

±12V電源に対して、オペアンプ入出力には十分な公称余裕を取っています。ただしデータシートの主な保証条件は±15Vであり、±12Vでの実負荷・過渡応答・クリッピングは実測対象です。DACのセトリング4.5µsは代表値です。25k点/sのシステム性能を保証するものではありません。まず1k点/sで確認し、SPIクロック4〜8MHzなどへの変更後に全ch転送時間とアナログ整定を測定してください。

## ARMとDB25

J3に維持型NO接点のARMスイッチ（できればキー式）、J4にNC接点の外部非常停止ループを接続します。ARM閉・非常停止ループ閉・G10 Highのすべてが成立したときだけ、4個の5Vリレーが励磁します（コイル合計約160mA）。G10は外付けプルダウンを設けています。

非励磁時はRGB±をGNDへ接続、シャッターは0V、インターロック4–17は開放です。励磁時にRGBをアナログ出力へ切替、シャッターを5V、インターロックを閉じます。これは起動・手動停止用で、点ごとの高速ブランキングにはRGBのDACデータを使用します。リレーとフライバックダイオードのため停止には遅延があります。

**このRev.Aには独立ウォッチドッグ、走査停止検知、±12V監視、接点溶着監視はありません。CPUがENABLE Highのまま停止した場合や接点故障時の停止は保証できません。** プロジェクタ本体のキー・非常停止・シャッター等も有効にして評価してください。実機のX-RGB 705の入力回路・停止動作は未確認であり、ILDA DB25があることだけで互換性を保証していません。

各使用信号の直前に独立切り離しジャンパを設けています。**初回はJP10〜JP25をすべてOPEN**。未使用DB25ピンはNCです。

|ジャンパ|DB25ピン|信号|
|---|---:|---|
|JP10 / JP18|1 / 14|X+ / X−|
|JP11 / JP19|2 / 15|Y+ / Y−|
|JP12 / JP20|3 / 16|Intensity+ / Intensity−|
|JP13 / JP21|4 / 17|Interlock A / B|

第6DACは予備IntensityとしてTP6とJ6 pin1に引き出しています。**Intensity用出力アンプは未実装**です。J6は1＝DAC_I、2＝I+、3＝I−、4＝GNDの外部変換回路接続用。外部回路を追加しない場合はJP12/JP20をOPENのまま使用してください。DAC_IをDB25へ直接接続しないでください。

ケーブルは全ピン直結のILDA用を使用し、両端の性別と導通を確認します。RS-232ヌルモデム／クロスケーブルは使用しません。DB25シェルはこの部品ではPCB接地されません。筐体・シールドの接地は装置側条件に合わせて別途検討します。

## 初期評価手順

1. **プロジェクタ・レーザーを接続せずに開始。** はんだ・電源短絡・電解極性・DIP向き・J1嵌合を点検。JP1＝1–2、JP2/JP3＝OPEN、RGB＝GND基準、JP10〜25＝OPEN、ARM＝OFF。
2. 電流制限付き5V電源でJ2へ給電し、5Vと±12Vを確認。R1/R2の発熱を確認し、異常な温度や消費電流があれば停止。CoreS3を別途給電し、3V3、VREF、VCENTERを測定。
3. ファームウェアの最初にENABLE Low、すべてのCSとLDAC Highを設定。表示初期化より先に行う。X/Y＝2048、R/G/B/I＝0を全chへ書き込み、LDACで反映。ARM OFFでRGB±≒0V、シャッター0V、インターロック開放を確認。
4. まだプロジェクタ未接続のままARM ON／ENABLE Highを試験。各DACの0・2048・4095を測定し、X/Y中心と極性、RGB利得を確認。RGB上限を校正。負荷模擬抵抗とオシロスコープで整定・オーバーシュート・ノイズを確認。
5. ENABLE Low、ARM OFF、非常停止、CoreS3リセット・電源断の各操作でRGB接地／シャッターOFF／インターロック開放へ戻るか確認。電源投入順序を変えた試験も実施。差動信号の負側に接地型オシロスコープのGNDクリップを接続しないこと。両チャンネルのGNDは共通GNDとし、差分演算または差動プローブを使う。
6. 電源OFF後に必要なDB25ジャンパを閉じる。Intensityは未使用ならOPEN。X-RGB 705の説明書・ケーブル導通・入力負荷と各停止機能を確認したうえで接続。最初はRGB＝0、XY＝中央。実光を扱う評価は光路を遮蔽し、機器に適した管理下で行う。
7. 小振幅XY（2048±102程度）、低い点更新速度から開始。異常・バッファ欠落時はENABLEをLowへ。安定後に速度・振幅を上げ、中心・最大振幅・RGB黒レベルを保存して校正。

## 検証範囲・調達

`verification/ERC.json` はERC指摘0件、`DRC.json` は違反0件・未接続0件・回路図一致問題0件です。プロジェクト固有の違反除外は使用していません。KiCad標準の無効チェック項目はDRC JSONに列挙されています。`nominal_dc.csv` は実際の接続・抵抗値を使った理想オペアンプの節点解析で、X/YとRGBのDC式を6条件で照合した結果です。実機試験、部品公差解析、過渡SPICE解析、EMC試験、安全認証の代わりではありません。

主要部品は秋月の商品・データシートを確認しました。価格・在庫は変動します。M5-Bus SMDコネクタ、完全一致の5.00mm端子台、外部ARMスイッチ・非常停止・ヒューズなどは別途調達対象です。抵抗の例：10kΩ＝108550、47kΩ＝108560、2.2kΩ＝108540、12kΩ＝108551。寸法・ピッチ・定格もBOMフットプリントと照合してください。

基板外の付属品：5V/2A電源、T2Aヒューズと絶縁ホルダー、維持型NO ARMスイッチ、NC非常停止スイッチ、2.54mmジャンパキャップ、絶縁スペーサー、適合する全ピン直結ILDAケーブル。任意でDIP14ソケット3個、DIP8ソケット4個（差動オプション時6個）。
